# VÅRD — Feminist Data Interface

A speculative feminist AI prototype designed as a proof-of-concept tool for IKEA, exploring care ethics, data transparency, and user consent as design principles.

Built as part of a Service Systems Design thesis at Aalborg University Copenhagen.

---

## What is VÅRD?

VÅRD (Swedish: *care*) is a data navigation interface that shows IKEA Family members what data the company holds on them — honestly, without euphemism, and grounded in feminist care ethics.

It is built on four principles:

- **Care ethics** (Joan Tronto) — distinguishing genuine care from care as commercial extraction
- **Transparency** — naming surveillance as surveillance, not "personalisation"
- **User autonomy** — supporting informed withdrawal, not just engagement
- **Intersectionality** — recognising that data risk is not equal across users

## Running locally

Just open `index.html` in a browser. The AI chat will not work locally without an API key — see the Netlify deployment section below.

---

## Deploying to Netlify (with working AI)

### 1. Get an Anthropic API key

Sign up at [console.anthropic.com](https://console.anthropic.com) and create an API key. Cost is approximately €0.003 per conversation message.

### 2. Deploy to Netlify

1. Fork or clone this repo
2. Connect it to [Netlify](https://netlify.com)
3. In Netlify → Site settings → Environment variables, add:
   ```
   ANTHROPIC_API_KEY = your_key_here
   ```
4. Deploy

### 3. Update the fetch URL in index.html

Find this line in `index.html`:

```javascript
const r = await fetch("https://api.anthropic.com/v1/messages", {
```

Replace with:

```javascript
const r = await fetch("/api/claude", {
```

Remove the `"Content-Type"` header line — the proxy handles authentication server-side.

## Academic note

VÅRD is a proof-of-concept prototype. The data shown (Sigrid Lindqvist's profile) is simulated. The AI responses are generated by Claude and instructed to apply feminist care ethics principles — they do not represent actual IKEA data practices.
